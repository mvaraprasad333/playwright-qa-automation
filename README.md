# QA Automation Framework 🚀

A modern end-to-end test automation framework built using **Playwright, TypeScript, and Cucumber BDD**.

## 👨‍💻 About This Project

This project demonstrates my hands-on experience in designing and developing scalable QA automation frameworks for web applications.

The framework focuses on maintainability, reusable components, reliable test execution, and CI/CD integration.

## 🛠️ Tech Stack

- Playwright
- TypeScript
- Cucumber BDD
- Gherkin
- Node.js
- Page Object Model (POM)
- API Testing
- Git & GitHub
- CI/CD
- HTML Test Reporting

## ✨ Framework Features

- End-to-End Web Automation
- Cucumber BDD Scenarios
- Page Object Model
- Reusable Step Definitions
- Cross-Browser Testing
- Parallel Test Execution
- Retry Handling
- Screenshots on Failure
- Test Reporting
- Environment Configuration
- API Testing
- CI/CD Integration

## 📁 Project Structure

## 🧪 Sample BDD Scenario

    Feature: User Login

      Scenario: Successful login with valid credentials
        Given the user navigates to the login page
        When the user enters valid credentials
        And clicks the login button
        Then the user should be successfully logged in

## ▶️ Running Tests

Install dependencies:

    npm install

Run automated tests:

    npm test

## 📊 Test Reporting

The framework supports automated test reporting to provide clear visibility into:

- Passed scenarios
- Failed scenarios
- Execution duration
- Failure screenshots and debugging information

## 🔄 CI/CD

Automated tests can be integrated into a CI/CD pipeline to execute regression suites automatically and provide test results after execution.
